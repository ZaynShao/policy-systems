# 政策库已知数据坑

都是实战踩出来的，选目和装配时逐条防。

## frontmatter 全字段不可靠

| 字段 | 实际是什么 | 后果 |
|---|---|---|
| `issuer` | 常是采集省份，不是发文机关 | 国务院文件被写成地方件 |
| `date` | 可能是成文日、生效日或发布日，不统一 | 按窗口扫会漏掉跨月件 |
| `official_number` | 可能抓到页面侧栏噪声 | 文号张冠李戴 |
| `id` 前缀（SC/HN 等） | 只是采集渠道，不是行政区划 | 误判国家/地方层级 |
| `region.name` | 采集站点所属地 | 同上 |

**一律以 RAW 正文的文头、文号、落款为准**，用 `verify_head.py` 逐条核。

实例：《可再生能源发展"十五五"规划》（发改能源〔2026〕1067号，国家发改委+国家能源局）经山西站点采集，frontmatter 标 `region: 山西省`。

## 成文日 vs 发布日导致窗口漏件

按 frontmatter `date` 扫窗口会漏掉「上月成文、本月发布」的件。

实例：《能源领域节能降碳行动计划（2026—2028年）》成文 6-26、发布 7-10，`date` 记的是成文日，7 月窗口扫不到——这是当期最大的漏项，靠 web 查漏才补回来。

**对策**：窗口下界适当前推，或扫完后专门查一遍"本月发布但成文在上月"的件。

## 正文乱码（UTF-8 被按 latin-1 解码）

形如 `2026å¹´7æ31æ¥`。可无损还原，但有个陷阱：

**逐行修复时必须用 `text.split("\n")`，不能用 `splitlines()`。** 乱码字节里含 `\x85`(NEL)、`\x0b` 等，`splitlines()` 会把它们当换行符，切断多字节序列导致整段修不回来。`scripts/common.py` 的 `demojibake()` 已处理。

个别文件 RAW 本身丢字（如四川 291 号文的执行年月为空），这种不可引，记 dq。

## pid 与文号错绑到「被引用的文件」

比 pid 撞车更危险，因为错得很合理、不容易察觉。

两种来源：

- **绑到正文引用的上位文件**。实例：四川《2026年电力需求侧管理实施方案》真实文号是 `川发改能源〔2026〕232号`，库里却是 `id: P_2026_SC_FGW_1283` + `official_number: 发改运行规〔2023〕1283号`——绑到了它引用的 2023 年国家文件。西藏、黑龙江的成品油流通件被填成 `国办发〔2025〕5号`，同理。
- **绑到页面侧栏另一份文件**。实例：《可再生能源消费最低比重目标和消纳责任权重制度实施办法》是 2026 年第 42 号令，pid 却是 `P_2026_NDRC_698`——698 是侧栏链接里另一份文件（发改环资〔2026〕698号）的文号。

反过来用：**侧栏噪声本身是查漏线索**。上例里那个被错当 pid 的 698 号《重点行业节能降碳改造攻坚三年行动》，经核实库中确实没有独立采集，是一件真漏采。看到 pid 与正文文号对不上时，顺手查一下那个"外来文号"指向的文件在不在库里。

危害面比撞车大：凡拿文号做关联的下游都会串件，串到的还看着合理。**凡引用文号必回正文核**，`verify_head.py` 抽的是正文文号，与 frontmatter 不一致时以正文为准。

## pid 撞车与多渠道重采

两种不同情况，处理方式不同：

- **真撞车**：两份不同政策共用一个 pid。实例：`P_2026_JS_FGW_10` 挂了 **7 份**不同的江苏成品油调价公告（2026-04-21 至 07-17，横跨四个月）；`P_2026_HA_X_4` 挂了 5 份不同的市场监管总局文件。这不是偶发，是渠道级的 id 生成缺陷。必须靠 `title_hint` 区分。
- **重复采集**：同一政策被多个渠道采到。实例：国务院碳达峰方案 4 份、某国家级文件 2-3 份。取正文最长且带文号的一份。

`pack_build.py` 的 `pick_file()` 两种都能处理，但 slate 里要给准 `title_hint`。

## 数字在未采集的附件里

价格表、容量表、项目清单常以 PDF/WPS 附件形式发布，库里只有正文。

实例：输配电价的省级电网价表、成品油调价的各省价表、分布式光伏可开放容量表——正文里一个数字都没有。

**凡涉具体价位一律不得推算**，记 dq 并在稿件里说明"具体以附件价表为准"。少数省份的转发件正文会载明幅度，可用但要注明出处省份。

## business_view 打分失准

打分层的产出质量不稳定，不能用来截断候选：

- 旗舰件漏评：发改能源〔2026〕1067号五年规划完全没有打分文件
- 跨条线件低估：财税类国家级公告只给 1-2 分
- 无关件混入：市场监管局的医疗器械经营公示、股权出质登记公示等混在候选池

**打分只作信号，编辑判断主导。** 成品里不要留"—"，编辑直接给分并在 slate 记明理由。

## 旗舰规划正文缺失

有些重要规划，库里只有「印发通知」，规划全文在附件里没采到。

实例：1067 号只有通知正文（约 800 字），《可再生能源发展"十五五"规划》全文不在库。

**对策**：只引通知载明的事实（机关、文号、依据、印发对象），解读部分说明"规划全文以附件形式发布"，不要凭想象写规划内容。

## 空正文（只有导航壳）

个别文件标题看着高度相关，去噪后净正文 0 字——采到的全是页面导航，正文没抓下来，且往往没有 business_view。

实例：深圳《2026年电力负荷管理实施方案》。

**对策**：装配后检查 bundle 的正文字数，接近 0 的按漏采处理进 appendix，不要硬写。

## 关系层伪边

`relations_canonical.jsonl` 里的边不都是真实引用关系。兄弟省份的同类文件之间常出现 `cites_basis` 边，实际只是它们引用了同一段上位文件的样板文字而触发的。

**两个方向都不能反推**：不能据伪边写"某省引用某省"；也不能因为某组文件关系层零覆盖就判断它不重要（储能类文件常整组无边）。关系边只作线索，承接关系要回正文确认后写成自然句。

## 采集源污染

候选池里有大量与能源无关的日常政务件（市场监管的许可公示、医疗器械备案、股权出质登记等），某月可占候选量的近一半。评论层里泛科技媒体也占比很高。

这不是 bug，是采集渠道的固有噪声——**选目时靠标题逐条筛，不要指望打分层帮你过滤**。

## 已知采集盲区

跨条线机关发的能源政策容易漏采，动笔前 web 查漏重点扫这些：

- 财政部 / 税务总局（能源税费、车船税、土地使用税、消费税）
- 海关总署（进出口相关）
- 金融监管、交易所、期货（电力期货、算力期货这类）
- 工信部（电池、新能源汽车产业政策）
- 市场监管总局（充电桩认证、计量、抽查）

## 2026-08 月刊新增实测（2026-09-03 / 09-15）

**pid 撞车新实例**：`P_2026_NDRC_979` 同时挂煤炭工业"十五五"规划（发改能源〔2026〕979号）与沈阳转发的 8/14 成品油调价；`P_2026_HA_X_8` 挂两条河南市监无关件；`P_2026_JS_FGW_10` 继续撞（第 15/16 号调价）。

**pid 错绑新实例**：四川辅助服务费用分摊函（真实文号川发改价格函〔2026〕332号）pid 绑到它引用的国家件发改价格〔2024〕196号；宁夏储能通知也绑到 196 号；西藏、辽宁成品油细则 pid 尾号 `_X_5` 取自国办发〔2025〕5号。196 号与《售电公司管理办法》（发改体改规〔2021〕1595号）本身都不在库里，这就是"外来文号是漏采线索"的实例。

**发改委页面"相关政策"侧栏噪声**：1055/979 号通知的 RAW 文号列表混入 942 号，关系层据此生成 references 边，不是引用关系。

**frontmatter date 误标**：市场监管总局 8 月 5 日的半年度计量通报 date 被标成 2026-01-01，窗口扫描漏掉，靠 web 查漏点到后回库才找到。日期误标和成文日问题叠加，所以 web 查漏结果一定要先回库 grep。

**跨月捞回已内建**：`scan_window.py` 现在同时输出"date 早于窗口、fetched_at 在窗口内"的件（`cross_month: true`，打印标 ↩，默认回看 75 天）。8 月窗口实测捞回 47 条，其中 942/1055/979 号规划、江苏 695 号、湖南 460 号、四川 332 号六件正式入选。注意捞回里也混着历史重采的无关件，照样逐条看标题。

**去噪吃掉拆行的文号数字（已修）**：乱码件（如川能源〔2026〕47号的页面）里"发改体改规〔2021〕1595号"被抓成五行"〔 / 2021 / 〕 / 1595 / 号"，`clean_body` 的纯数字短行过滤会把数字行整行删掉，bundle 里只剩"〔 〕号"，F 门据此报"数字缺失"。`common.rejoin_split_numbers` 已在去噪前按四种结构（拆开的年份、〔年〕号文号、年第N号、年月日）把它们拼回去，全库回归并行只发生在日期与公告号上。遇到审计员说 bundle 数字缺失，仍先回库原文核一遍。

**三份"十五五"专项规划库里都只有通知加通稿**（942 电力、1055 油气、979 煤炭），规划全文在附件；942 与 1055 各有 gov.cn 政策库版（成文日为 date）、部委站点版、通稿版三份，用 companions 合并。油气规划的答记者问是用户裁定补采到 supplement/ 的，没有它加油线写不深。
