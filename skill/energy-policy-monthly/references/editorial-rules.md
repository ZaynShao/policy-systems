# 内容纪律与风格

## 业务边界

**不要在这里读业务定义，去读 vault 的权威文件**：`_meta/framework/business_strategy.yaml`（`status: active` 的那份）。

这是硬要求。framework 自己记着一次教训：2026-08-31 之前各环节都手写自己的业务口径，结果"四份手写口径三套词表，枚举里还留着退役类目"，整批标 `retired_tainted`。本文件曾经也是手写副本之一，下面几条就是被它推翻的：

| 旧口径（已废） | 实际情况 |
|---|---|
| 加油"汽油为主，柴油少" | 油品品种在战略材料里 0 次提及，属 `scope_absent`，材料空白，不是业务边界 |
| 充电"重卡占比小" | 重卡/商用车/货车 0 次提及，是 absent 不是"占比小" |
| 乡村/农村"退役原型污染" | 县域/农村场景 0 次提及，同样是 absent |

**`scope_absent` 的唯一合规写法**："X 场景在现有业务材料中未见安排，是否跟进需业务方裁定。"不能写"公司不做 X""X 不在当前打法之内""X 占比小"，也不能把它当成业务场景正面展开（例如"充电业务的县域场景"）。8 月刊 D 门就是在高速、重卡、县域三处抓到了这个毛病。

三条业务线（2026-09-02 裁决为三板块 fuel / charging / power）对选目最有用的抓手，仍以 yaml 为准：

- **加油**（守成）——决策变量是批发价、炼厂装车价（利润来自折扣空间，不是零售挂牌价），以及商户合规成本、KA 总部对外合作与支付接口口径、下沉城市展业可行性。轻资产平台，不持有不建设不运营油站。
- **充电**（战略重心，唯一有定量目标的线）——年增长 >40%、份额 35%、供给侧转移窗口 2-3 年（均标"数字待核"）。车辆只有三类且全是乘用车：网约车、营运车、私家车（2026 重心）。讲的全是公共充电场站。决策变量含场站侧电价结构、大功率超充升级成本与合规门槛、标准话语权。
- **电力**（建能力，给耐心）——售电与电力交易，现货是主战场。储能当前 hold（因政策性峰谷价差要停）。虚拟电厂与储能是"供应链"项下抓手，不与电力交易并列；若必须二分按客户场景（充电场景／工商业场景），不按品种分。写"电力业务项下储能项目"，不写"储能业务"。

**电力线有个直接可用的选目判据**：`province_filter`。已进入湖南、陕西；2026 目标省江苏、浙江、福建、四川、重庆、湖北、湖南、陕西、南网五省。同一份文件落在这些省，相关性显著更高。

`_meta/framework/` 下的 `report_blueprint.yaml` 与 `factcheck_rules.yaml` 标了 TAINTED，不用。

## 剔除范围

**油价变动类内容整体不入政策分析范围**：成品油调价、调价幅度、批零价差、价格波动区间一律不写。slate 里把调价组标 `excluded`，不装配。

边界要分清：碳达峰方案里的"油品消费达峰"、绿色燃料替代路径、成品油消费税与定价机制研究、加油站用地税负，这些是政策方向，保留。涉及定价机制时用"批发价与装车价的形成方式"，不用"批零价差"一词，免得被当成油价内容。

## 内部文件

通过非公开渠道拿到的材料是团队的高价值体现，要明确呈现而不是匿名化。两种类型规格略有不同：

**正式文件类**（如某期的一份内部正式文件，个人版已隐去名称）：
- 【政策信息】写明"标注内部、未见公开渠道刊发、经政府高层渠道先行获取"
- 速览表日期栏标"MM-DD成文·内部"
- 概述里点一句，说明市场多数参与者还看不到
- 扫描件无文本层的，逐页视觉转写成审计用转写稿，与原件一并归档 `internal/`

**交流纪要类**（如某期的一次拜访交流，个人版已隐去单位）：
- 详情标题写"（内部·政府高层渠道获取）"，【政策信息】写"来源单位 / 形式：公司拜访交流纪要 / 时间 / 文号：无"，正文说明"经政府高层渠道先行获取、未见公开渠道刊发、不是正式文件、内容为处室口头口径"
- **不点名任何个人**（含对方领导），只写到处室；公司名也不出现
- 所有数字标"据交流""交流口径"，有公开统计口径不一致的加一句"公开统计口径略低于此数"之类的限定
- 口头口径不能写成"文件规定"，用"办法将规定""据处室介绍"
- "预计 X 月底挂网"这类预告，发稿时未兑现的要写"截至发稿未见"
- 纪要原文有明显笔误（如"服务服务市场品种"），按合理还原写并在 slate dq 记明
- 拜访日期用户没给时，速览表写"MM月·内部"，不要编

内部件无法 web 交叉验证，事实以原件为准，dq 里记明。

## 补采材料

用户裁定补采的公开材料（答记者问、解读、报道原文）放 `supplement/`，不写进库。成品里引用时标明来源（"据国家能源局答记者问"），逐字引。只有报道没有文件正文的政策，用户裁定一般是只进附录、不入正文，数字标"据 XX 报道"。

## 层级

**省级政策不与国家级并列详述**：

- 省级承接件 → "落地综述"
- 地方件整体 → 详情里合并成一节，先总起段点明本月地方的几条线，再把最有操作价值的一两件用「关键词 / 承接国家级 / 对公司业务」紧凑单列，其余并入"其他地方政策合并速览"
- 区级件（如区商务委的消费券平台征选）最多在合并速览里一句
- 地方速览表日期统一用公开日，与详情节的"成文、公开"两个日期都写清

## 篇幅预算

8 月刊第一版 1.16 万汉字，读者评"冗杂"，返工到 0.94 万。以后按这个写：

| 部分 | 预算 |
|---|---|
| 全文正文汉字 | 9000 到 10000 |
| 概述 | 不超过 4 段，每段不超过 220 字；只写主线，不复述详情节里的数字 |
| 关联速判 | 每条不超过三句 |
| 【政策信息】摘录 | 每件不超过 5 条，只留与业务直接相关的；可用省略号跳接；印发对象概括写，不逐字罗列 |
| 【政策解读】 | 2 到 4 点，每点 2 到 3 句 |
| 【重点关注内容】 | 2 到 3 条，只放政策观察点，政府关系动作放决策建议 |
| 地方合并速览 | 每段不超过 250 字，常规配置类件（竞争性配置、容量公示）合并一句或删 |
| 附录 | 不超过 9 条，小项合并到"其他动向"一条 |

## 风格

**无机器残留**——正文里不能出现：

- 政策 id（`P_2026_*`、`INTERNAL_*`）
- 主题码、维度码（D1-D6）
- ⭐、「」直角引号、markdown 加粗星号
- 工程词汇：vault、bundle、frontmatter、pipeline、slate、pack、采集、数据侧
- 过程性元信息："本期截稿时点""数据未覆盖""扫描发现""据本刊核查…未见…文件""缺项/补回"

**去机器腔**——读者能一眼认出的 AI 写法，一律不用：

- 框架句开头："三点判断：""含义有四层：""从三个方面看"。直接写编号要点。
- 比喻和套话："共同指向""共同定义了""外部前提""锚点""底盘""读数""筹码""就此定型""不再只是…而是…""从灰色地带推向违规""值得注意的是""可以说""无疑""不难看出""综上""某种程度上"。
- 自拟标签加引号：引号只给逐字引文用；自己概括的词组（如 炼能收缩、消费达峰）不加引号。
- 分号串联三四个分句的长句。一句话说一件事，超过 75 字的句子按句号拆开。
- 并列的"一是…二是…三是…"用于列条款可以，用于解读里的判断要少用。

**其他**：

- 评分统一写"N分"，成品里不留"—"
- 承接关系写成自然句，不列关系表，不出现"关系边"
- 敢下结论，不堆"可能""或许"；本刊自己推论的地方标"本刊的推论是"
- 解读要有增量判断，不能只是复述原文；不要重复上期的判断句，写本期的增量
- 缺席性断言（"首次""第一次""唯一""未见"）必须有事实源支撑，没有就改成限定表述（"据答记者问，规划在市场机制部分写入…"）
- 比例要写清分母（"发售一体企业内部交易签约电量 20% 比例限制"，不是"20% 集中度"）
- 学旧刊只学版式和口径，不抄内容点

## 打分口径

参照往期：

- **5分** — 顶层文件、五年规划、对业务组合有直接模式定义的重磅件、提前量最强的内部件
- **4分** — 国家级执行文件、价格基线类、行业五年基准（影响面大但不改变格局）
- **3分** — 国家级硬约束但影响面较窄（财税退坡、强制认证、执法通报）；目标省的规则细则
- **2分及以下** — 一般不进详情

打分缺失或明显失准的，编辑直接定分并在 slate 的 `editorial_score` 记明理由（漏评补分还是失准上调）。
