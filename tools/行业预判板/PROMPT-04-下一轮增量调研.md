## §2 推力(push)判定细则 ★本轮新增,逐节点重判
温度量的是**监管强度**(规则与执法的密度与方向),不代表国家对产业的态度。上一轮把"新增规则 = 收紧"贯彻得太严,本轮按下表重判**每一个**节点:

| 记 | 条件 | 典型 |
|---|---|---|
| **up 收紧** | 限制、禁止、总量控制、清退、处罚与执法通报、专项整治、提高准入门槛或资本金、新增**带罚则或硬期限的强制义务**、税费加征 | 售电公司准入门槛提高、强制投保 2027 硬期限、"黑飞"执法典型案例、补贴行为规范十条、清退 32 家 |
| **dn 支持** | 规划/意见/行动方案等促进发展、试点扩围、放开准入、补贴与要素保障、简化审批、目标值上调、设施与项目开放、消费促进 | 三年倍增行动、首批 L3 许可、以旧换新、设施开放清单、十五五规划 |
| **0 中性** | 技术标准(含强制性国标)、适航/准入技术基线、安全指引与指导性技术文件、运行识别/注册/备案等程序性规则、执行衔接件、立法计划、共用件(政府工作报告等)含双向内容、法律/法规同时含促进与义务条款、数据发布、机关表态双向 | 自动驾驶强标、无人机适航标准、空管规则增无人机条款、"管得住才能放得开" |

补充规则:
- **同一规则线只在关键节点计一次方向**:征求意见→正式发布→配套解读→省级承接,只在最能代表方向的一件(通常是正式件)标 up/dn,其余标 0,并在 `use` 写"同线,方向计在 F<n>"。
- **多城同类动作**:最多 2 条计方向,其余标 0(D1 的"合并簇"对温度也生效)。
- 法律/行政法规若既有促进条款又有义务条款 → 0,并在 `use` 里各引一句。
- 判不准就标 0 并写进 `meta.stops`,不要往 up 靠。
- 每个改动的节点在 `note` 写"<日期> 本轮按 §2 重判:push x→y"。

### §2.1 边界口径(D9,2026-09-15 用户裁定"按 S0 建议")
各组在 §2 下判法不一的边界项,统一如下;与 S0 2026-09-15 D 复核不同处以本节为准:
1. **法律/行政法规/部门规章同时含促进与义务条款 → 0**(道交法修订草案自动驾驶专章、民用航空法低空条款)。
2. **指导性文件(指引/指南/实践指南/指导性技术文件)、技术标准(含强标)、程序性规则(投诉处理、认证、注册、备案办法)→ 0**,即便针对特定行业(汽车行业境外竞争与合规建设指引、个人信息出境认证办法、旅游投诉处理办法)。
3. **共用件(政府工作报告、国务院年度立法计划、"两新"通知等多行业同引件)→ 0**;其促进或规范内容进"产业方向"判定,不进温度。
4. **同一规则线只在正式件计方向**,征求意见稿、配套解读、承接件、施行提示 → 0;**多城同类动作最多 2 条**计方向,其余 0。
5. **执法与整治 → up**:处罚通报、典型案例、专项整治部署、提醒告诫、合规提示、约谈;同一整治的多批通报最多 2 条计 up。
6. **带罚则或硬期限的强制义务 → up**,即便对第三方是保障(职业伤害保障全国推开对平台是强制参保义务;强制投保;存量设备加装期限)。
7. **机关表态**:单向促进(明确"支持""加快""扩大")→ dn;单向收紧 → up;双向或含糊 → 0。座谈会、部署会、发布会同理;自律公约、倡议 → 0。
8. **判不准 → 0**,写进 `meta.stops` 请用户裁定,不往 up 靠。
9. S4 内部件仍按 D6 计(×0.5 级别权重);S2 央媒 context 跟随所报道事实的方向,×0.5 角色权重。

## §3 产业方向(direction)★本轮新增
每个行业填 `direction`:`stance` 支持/中性/限制;`basis_fact_ids` ≥1 条 S1 国家级 fact(可为窗外锚点);`note` 写依据哪份文件的哪句措辞;`judged_by`、`judged_at`;`confirmed` 先填 false。

- 上一轮 S0 草案与子 agent 调研结论在 `assessment/产业方向调研-2026-09-15.md`,可复用其依据 URL,但要按本轮窗内新文件复核。
- 方向与温度**分开写**:一个行业可以"产业支持 + 监管趋严"。
