# 政策研判各系统（个人版）

我（ZaynShao）在公司项目 safety-platform 里做的几个政策研判系统，只取我本人的提交，单独成一个项目；别人在原项目里的提交一律不收。
按原来的先后，一个原 PR 对应这里一个 PR，逐个合并；我本机的 skill 和工具按日期穿插进去；最后几个 PR 是各系统的独立版收尾
（脱离原平台能装依赖、构建、跑测试，带真实演示数据，能生成双击就能打开的离线页面）。

政策预判 V2 另有独立仓库 `ZaynShao/policy-predict-v2`，不在这里。政策分析 pipeline 并入公司项目之前的历史在我的
`ZaynShao/policy-analysis-pipeline`；工单研判的本机取数、脱敏、上传客户端在我的 `ZaynShao/gov-ticket-risk`。

## 直接看

`离线页面/` 下是 6 个系统各一个单文件页面，下载下来双击就能打开，不用联网（说明见 `离线页面/README.md`）。

## 怎么跑测试

```bash
cd services/policy-pipeline && python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt && .venv/bin/python -m pytest
cd services/policy-qa && python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt && .venv/bin/python -m pytest
cd services/heng-guan/frontend && npm ci && npm test && npm run typecheck
cd services/heng-guan/backend && npm ci && npm test && npm run typecheck
cd services/guardian-backend && npm ci && npm test
node portal/personal-workspaces/pending-gov-risk/build.mjs --typecheck --check   # 先在 services/heng-guan/frontend 下 npm ci
node --test portal/tests/gov-risk-workbench.test.cjs services/guardian/test_gov_risk_transport.test.js
python3 -m unittest tests/test_policy_predict_industry_board.py
```

2026-11-19 在 Python 3.10、Node 25 上实测：pipeline 1260 项通过、1 项要本机政策库跳过；问答服务 194 项通过、8 项要真数据库跳过；
公共事务前端 40 项、两个后端、工作台 14 项（1 项要平台网关配置跳过）、行业预判板 3 项（3 项要政策研判外壳跳过）全部通过。

## 收了什么、没收什么

- 只收我本人的 PR（原项目 49 个里，政策预判 V2 的 5 个在另一个仓库；团队协作流程文档 PR 5 不算系统；PR 15、20 只改了同事页面里的
  几行，没有能单独成立的内容；PR 999 先合进了别的分支，按重新落地到主干的 PR 1043 收）。
- 原 PR 里改在同事建的文件上的部分，逐个 PR 重放时不收；其中几处是我的主要成果（政策解读页的问答界面、月刊新版排版、消息铃铛、
  工单研判的数据表、政策大盘对齐 L2 等），在各系统的收尾里把我写的那几段原样拆成单独的文件，配上最小外壳，同事写的行不带。
- 同事在我的文件上后来做的改动不收；从同事页面复制来的文件（我的工作台里的政策大盘、图谱、知识库等）不收。
- 公司内部信息（标着内部了解、内部渠道获取的三件信息）隐去了原文，换成「内部信息，个人版已隐去」，分数与推理结构不动；
  涉及的提交在说明里注明了。
- 每个 PR 的说明里写了收了什么、没收什么、和原 PR 差在哪。
