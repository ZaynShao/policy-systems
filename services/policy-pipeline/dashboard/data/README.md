**数据截至 2026-11-08**:政策库最后一次提交 `2ab3d7c5b`,2026-11-08 03:00 的夜间派生信号(服务器上的

## 三个文件

| 文件 | 内容 | 怎么算的 |
|---|---|---|
| `overview.json` | 链路每段的件数:L1 原文、编号、撞车、渠道;L2 打分、主题、影响分析、摘要、关系;政策库各目录;四个出口 | 原文按 `scripts/l1_audit/corpus.py` 的读法;平台库行数用 `scripts/sync/run_sync.py` 的取行函数(只算不写库);对外接口用 `scripts/public_export/run.py` 的导出函数 |
| `audit.json` | 守恒巡检 ①③④ 的完整清单,② 写明算不了 | `scripts/service/conservation_audit.py`(原项目 PR 1184)的 `run`,today 取数据截至日 2026-11-08,渠道目录用本仓 `state/T1_channels/channel_catalog.yaml`,豁免表 `config/audit_exemptions.yaml`(三节都空) |
| `policies.json` | 政策库条目 2,102 条:编号、标题、文号、机关、发文日、层级、地区、原文链接、正文开头、客观摘要、L2 主题打分与影响分析、链路状态、相关政策 | 原文 `0_raw/policies/`;摘要 `1_extracted/policy_summaries.jsonl`;L2 `_meta/business_view/`;关系 `1_extracted/relations/`;主题名 `_meta/themes_registry.yaml` |

主要数字(截至 2026-11-08):政策原文 2,138 篇、2,090 个编号(27 组 75 篇编号撞车);评论、解读 4,029 篇;
L2 主题打分 1,816 份(挂主题 769、影响分析 743);平台库应写入 1,789 行;对外接口可导出 2,137 篇;
守恒巡检 ① 285 篇、③ 18 篇、④ 停更 39 条 + 从未出件 9 条 + 市级可疑 40 条。

## 政策库各目录是什么

| 目录 | 是什么 | 看板用不用 |
|---|---|---|
| `0_raw/policies/` | L1 政策原文,入库后不改 | 用 |
| `0_raw/commentaries/` | L1 评论、解读原文 | 只数篇数;巡检③读它找被反复点名的政策 |
| `0_raw/_archive/`、`_duplicates/` | 重抓换下的旧版、去重隔离 | 只数篇数 |
| `1_extracted/` | L2 通用派生:客观摘要、9 类关系、评论信号、市场信号 | 用摘要和关系(关系只带类型和对方编号,不带证据原文) |
| `_meta/business_view/` | L2 业务派生:六维打分、主题、影响分析、行动建议 | 用 |
| `_meta/themes_registry.yaml` | 13 个业务主题的中文名 | 用 |
| `2_crystallized/` | 结晶层:主题页、地区页(维持,不再更新) | 只数页数 |
| `3_lints/` | lint 报告(停在 2026-04) | 只数份数 |
| `_quarantine/` | 隔离区:转发来的重复件 | 只数篇数 |
| `00 背景资料/`、`开发日记/`、`_meta/framework/` | 业务背景、工作日志、业务战略画像等内部资料 | **不读** |

## 没放进来的、改动过的

- 条目列表里不放 36 条(链路件数照算):人员名单类公告 34 条(招聘、面试、专家名单、资格人员名单等,正文是人名),
  标题、摘要或 L2 里点了个人姓名的 2 条。
- 公司内部信息(标着内部了解、内部·未见公开渠道、内部文件、拜访纪要之类):政策库里没有这类条目,看板里是 0 条;
  `export_data.py` 里写了这条规则,以后重录遇到会整条不收。
- L2 文字里有 3 处机构电话、邮箱,换成了「(电话略)」「(邮箱略)」,别的一字不改。
- 正文只带开头约 300 字:去掉网页导航、栏目菜单,去掉含联系方式和职务称呼的句子(称呼前后常是人名);乱码行按
  UTF-8 还原,还原不了的丢掉。
- 编号撞车的同组文件:L2 只挂在它实际算的那一篇上(按 `sanitized_from` 对),同组其他篇显示「L2 是按同编号的另一篇算的」。
- 省份按区划代码前两位判;缺区划代码的,依次按地区名、渠道目录里的城市、编号里的省份缩写(L1 发号规则)判。
