# 离线页面

6 个系统各一个单文件页面,下载下来双击就能打开,不用联网、不用起服务。演示数据已经打在页面里,在页面上的操作
(裁决、标已读、跟进、撤下之类)只在当前页面生效,刷新就还原。

| 页面 | 内容 |
|---|---|
| `行业预判板-独立版.html` | 24 个行业的监管走向预判:方块看板、预测卡、证据链、加工过程;说明条里可切到完整工作记录 |
| `政策分析pipeline-独立版.html` | 链路看板:L1 采集 → L2 分析 → 政策库 → 四个出口每段的件数、守恒巡检,政策库 2102 条可搜可筛 |
| `政策问答助手-独立版.html` | 政策解读问答:8 轮在测试站上真实问出来的回答,按原节奏重放(点页面里的示例问题) |
| `月刊产线-独立版.html` | 2026 年 7–10 月四期能源政策月刊,新版排版 |
| `工单研判工作台-独立版.html` | 我的工作台:总览 + 政诉预判;工单是编的脱敏样例,研判结果是用研判引擎算出来的 |
| `公共事务平台政策功能-独立版.html` | 消息铃铛、L1 源质量审核、政策大盘按 L2 主题与区划、移动端拜访语音录入 |

在 GitHub 网页上点开只能看到源码:点「Raw」或「Download raw file」存到本机再双击打开。

这些文件是按根目录 README「有哪些系统」里的命令生成的,与源码、演示数据一一对应;改了源码或数据要重新生成再放进来。
